# Inactive legacy loadout source

These files are retained for feature-parity reference and history, not linked,
registered, parsed as active built-ins or installed. They depended on private
host/engine/XML/menu paths and must not be re-added as a fallback. The active
consumer is `plugins/loadout`; unsupported legacy slots and defaults remain
explicitly pending public G6 extensions/verified adapters. Relative includes
refer to the former source layout; this archive is not a buildable target.

Private quantum boost/cvar keeper implementation is not part of this archive
and remains unchanged pending separate Step 4C approval.
